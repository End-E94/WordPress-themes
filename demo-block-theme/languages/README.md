# Translations

Demo Block Theme is translation ready and uses the text domain demo-block-theme.

To translate the theme:

1. Create a .pot file with WP-CLI: wp i18n make-pot . languages/demo-block-theme.pot
2. Open the .pot file in Poedit and create a .po file for your language.
3. Save the generated .mo file in this folder, for example demo-block-theme-de_DE.mo.

You can also translate the theme from translate.wordpress.org once it is published on WordPress.org.
