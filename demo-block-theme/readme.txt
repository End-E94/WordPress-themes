A flexible, accessible block theme for any website.

== Description ==

Demo Block Theme is a block theme built for the Site Editor. It ships with block patterns, a neutral color palette and style variations.

== Installation ==

1. In your admin panel, go to Appearance > Themes and click Add New.
2. Click Upload Theme and choose the theme zip file, then click Install Now.
3. Click Activate to use the theme on your site.

== Frequently Asked Questions ==

= Can I customize the colors and fonts? =

Yes. Use the Site Editor and the style variations to change colors, fonts and layout.

= Does it use external fonts or scripts? =

No. The theme uses system fonts and loads nothing from external servers.
